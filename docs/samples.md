# サンプルプログラム一覧

## 一覧

- `comp.txt`
- `fibo.txt`
- `prime.txt`
- `score.txt`
- `sum.txt`

## `comp.txt`

2 つの変数 `a` と `b` の大小関係を比較するプログラムです。
`a = 10`、`b = 20` なので以下の出力になります。

```txt
b の方が大きいです
```

## `fibo.txt`

引数 `n` に対するフィボナッチ数を計算する関数 `fibo` を 1 から 9 まで呼び出すプログラムです。
`print` を使っているため、値は改行なしで連続して出力されます。

```txt
112358132134
```

## `prime.txt`

引数 `n` が素数であるかどうかを判定する関数 `isPrime` を、グローバル変数 `a` で呼び出すプログラムです。
`a = 13` なので以下の出力になります。

```txt
a は素数です
```

## `sum.txt`

引数 `n` までの総和を再帰呼び出しで求める関数 `sum` の検証です。
`sum(10)` を呼び出しているため以下の出力になります。

```txt
55
```

呼び出し元の `n` を変更することで、スタックフレームのサイズによる実行時間の比較に使えます。

## `score.txt`

グローバル変数 `score` に定義域外の値が代入されるプログラムです。
最初に `80` を出力したあと、`score = score + 30` が定義域 `[0, 100]` を超えるため実行時エラーになります。

```txt
80
実行時エラー: 変数 score に定義域 [0, 100] 外の値 110 が代入されようとしました
  at vm STORE (out/score.json:3:1)
        {
    ^
```
