# サンプルプログラム一覧

## 一覧

- `comp.txt`
- `fibo.txt`
- `prime.txt`
- `score.txt`

## `comp.txt`

2つの変数 `a` と `b` の大小関係を比較するプログラムです。
以下の出力をもって正常動作。

```sh
b の方が大きいです
```

## `fibo.txt`

引数 `n` に対するフィボナッチ数を計算する関数 `fibo` を 1 ~ 9 まで呼び出しているプログラムです。
以下の出力をもって正常動作。

```sh
1
1
2
3
5
8
13
21
34
```

## `prime.txt`

引数 `n` が素数であるかどうかを判定する関数 `isPrime` を グローバル変数 `a` で呼び出しているプログラムです。
以下の出力をもって正常動作。

```sh
a は素数です
```

## `sum.txt`

引数 `n` までの総和を再帰呼び出しで求める関数 `sum` の検証。
呼び出し元の `n` を変更することで、スタックフレームのサイズによる実行時間の比較に用います。

## `score.txt`

グローバル変数 `score` に定義域外の値が代入されるプログラムです。
以下の出力をもって異常終了。

```sh
80
実行時エラー: 変数 score に定義域 [0, 100] 外の値 110 が代入されようとしました
  at vm STORE (out/score.json:3:1)
        {
    ^
```
